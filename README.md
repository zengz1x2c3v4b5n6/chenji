# chenji

高中成绩管理系统（单文件 HTML + Supabase 云端存储）。

## 内容

- 登录 / 注册（管理员发注册码）
- 成绩录入：9 科 + 总分班排 / 段排，单科也可填班排 / 段排
- 成绩记录：列表、搜索、修改、补填名次
- 成绩分析：选最多 5 场考试 → 定基准 → 单科或总分比对 + 成绩 / 班排 / 段排趋势 + 打印报告
- 注册管理：管理员生成注册码

## 部署

主文件 `成绩录入系统.html`，重命名为 `index.html` 后放在仓库根目录，即可用 GitHub Pages 访问。

数据层为 Supabase（项目 ref：dbwuzzfqggpbhzzdjpap），页面内使用 publishable key，表结构与授权见 `建表脚本.sql` 与 `安全加固.sql`。
